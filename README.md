# 🛍️ Cadastro de Produtos

Este é um projeto simples de **cadastro de produtos**, desenvolvido com o objetivo de praticar a integração entre **Python**, **MySQL** e uma **interface gráfica criada com Qt Designer**.

> 💡 Projeto desenvolvido com base nas aulas do professor **Neto Paschoal** no YouTube.

---

## 📌 Tecnologias Utilizadas

- 🐍 **Python** — linguagem principal do projeto  
- 🗄️ **MySQL** — banco de dados relacional para armazenamento dos produtos  
- 🎨 **Qt Designer** — ferramenta para criação da interface gráfica  
- 🔗 **PyQt5** — para conectar o Python com a interface gerada pelo Qt Designer

---

## 🎯 Objetivos do Projeto

- Criar uma interface gráfica funcional para cadastro de produtos
- Conectar a interface com um banco de dados MySQL
- Inserir, listar e manipular dados dos produtos
- Consolidar o uso conjunto de Python, MySQL e interface gráfica

---

## 📷 Interface

*A interface foi desenhada com o Qt Designer e conectada ao Python via PyQt5.*
